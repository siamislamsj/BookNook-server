# BookNook — Online Library

A JavaScript full-stack online library application built with Next.js App Router, Express.js, MongoDB Atlas, and Better Auth.

## Features

- Responsive public homepage with navbar, footer, and 3-slide Swiper hero.
- Latest 6 books from MongoDB and two editorial homepage sections.
- Browse all books with title/author search and category filtering.
- Detailed book pages with availability information and borrowing functionality.
- Email/password registration, login, and logout.
- Google OAuth sign-in.
- Add books with title, author, category, cover image URL, description, and total copies.
- Display book covers using externally hosted image URLs.
- My Books with owner-only editing and confirmed deletion.
- My Borrows with borrowing history and book return functionality.
- JWT-protected private APIs and owner authorization checks.
- Atomic book-copy decrement and restoration.
- Duplicate active-borrow prevention.
- Loading states, toast notifications, error boundary, custom 404 page, and route metadata.
- Separate frontend and backend deployment using Vercel.
- MongoDB Atlas database integration.


## Limitations

- Book cover images use externally hosted image URLs; direct image file uploading is not implemented.
